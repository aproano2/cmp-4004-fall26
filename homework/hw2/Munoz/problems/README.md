# Problemas SAT

- `problems.json`: 20 enunciados, variables y dificultad.
- `ground_truth.json`: CNF por condicion, testigos y numero de soluciones.

Hay 7 casos faciles (3-4 variables), 7 medios (5-6) y 6 dificiles (7-8). Todos son satisfacibles; se acepta cualquier asignacion valida.

Un literal positivo incluye la actividad; uno negativo la excluye. Cada clausula es OR y el conjunto es AND.

Dataset elaborado con IA y revision manual confirmada por el estudiante.
